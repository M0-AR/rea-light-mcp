The problem it solves

Full reverse-engineering servers expose ~139 tools with deeply nested settings (~1.9 MB of schemas, nesting up to 14 levels). Strict AI models reject any request when a single tool breaks their limits — even a plain hi:

Before: full catalog139 tools · ~1.9 MB schemas · depth 14 · recursive references · rejected by strict models
After: rea-light-mcp4 tools · ~1.5 KB schemas · depth 1–2 · zero references · accepted everywhere

How it works

The key trick: complex settings travel as a plain text string (args_json), so strict models only ever see flat settings. Real checking happens inside the server, unchanged.

🌱 Beginner guide — read this and you are a professional

1
What is MCP? A standard plug for AI assistants. A "server" is a small program that gives your assistant new skills (tools). You configure it once; every chat can then use it.
2
What is reverse engineering? Learning how a finished program works without its source code — which buttons do what, where data flows, how a file format is built. It uses only software you own or are allowed to examine.
3
Why the "light" version? The full toolset is so big that strict AI models refuse to talk while it is connected. This package shows the model 4 simple tools and keeps the other 139 behind the curtain — same power, no refusal.
4
Your first investigation. Install (below), then ask: "Using rea_investigate, open /usr/bin/ls and tell me what kind of binary it is." You will get format, architecture and fingerprint plus what to ask next.
5
The everyday loop. rea_search to find → rea_describe to learn settings → rea_call to run. After this page's quiz you will know more than most interview candidates.

Install

No install needed — run from npm

npx -y rea-light-mcp

OpenCode config (~/.config/opencode/opencode.jsonc)

{
  "mcp": {
    "rea":       { "type": "local", "command": ["npx", "-y", "rea-agents@6.4.0", "mcp"], "enabled": false },
    "rea-light": { "type": "local", "command": ["npx", "-y", "rea-light-mcp"], "enabled": true, "timeout": 120000 }
  }
}

Disable full rea (that is what strict models reject). Restart the session after editing. First run downloads packages — give it a minute.

FAQ

Is this a replacement for REA?

No — it is REA, through a smaller door. Same server, same checks, same results. If you remove the size limits (another model), full REA works too.

Why do deep tools fail without extra software?

Disassembly engines (Ghidra, Hopper, IDA) are professional tools you install yourself; this package never installs them for you. Opening and fingerprinting files works with nothing extra.

Does it upload my files?

No. Everything runs on your machine; the AI model provider only sees the text you discuss.

Can I allow renaming/commenting tools?

Yes: set REA_LIGHT_ALLOW_WRITE=1 in the server environment. Default stays read-only so accidents can't happen.
